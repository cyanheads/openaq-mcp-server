# 0.2.0 — 2026-09-23

## Added

- **`openaq_find_locations` `monitor`, `mobile`, and `providersId` filters**, forwarded to OpenAQ only when supplied (`false` included); each location gains `providerId`, so a filter value can be read off a prior result. ([#31](https://github.com/cyanheads/openaq-mcp-server/issues/31))

## Changed

- **Behavior change: `openaq_find_locations` rejects `coordinates` with `bbox`, or `radius` without `coordinates`, as `invalid_search_scope`** (`ValidationError`) — `{iso, radius}` and `{bbox, radius}` previously succeeded with `radius` ignored. `radius` drops its schema default; the service keeps the 12000 m fallback. ([#26](https://github.com/cyanheads/openaq-mcp-server/issues/26))
- **Behavior change: `openaq_list_countries` pages the filtered catalog** with `limit` (1–100, default 20) and `page`, so a call with no arguments returns 20 rows instead of the whole catalog. `totalCount` stays the full filtered count; `truncated`/`shown`/`cap` and a notice name the next page, and a page past the end is an empty result naming the last page. ([#28](https://github.com/cyanheads/openaq-mcp-server/issues/28))
- **Behavior change: non-positive ids are rejected at the schema** as `-32602` `invalid_arguments` before any OpenAQ request — `locationId` and `parametersId` on `openaq_get_measurements` and `openaq_get_readings`, `parametersId` on `openaq_find_locations` and `openaq_list_countries`, and `providersId`. ([#33](https://github.com/cyanheads/openaq-mcp-server/issues/33))
- **Behavior change: `openaq://location/{locationId}` declares `invalid_location_id` as `ValidationError` (`-32007`)**, not `NotFound`, so a malformed id is distinguishable by code from an unknown station; the reason and recovery hint are unchanged.
- **Docs and metadata:** `openaq_list_parameters` descriptions drop the stale `~44` / `~38` catalog counts; the server instructions say "widen the search area"; README and `docs/design.md` reconciled with the new schemas, errors, and enrichment; `CLAUDE.md`/`AGENTS.md` declare the gated release PR mode.

## Fixed

- **`openaq_find_locations` derives `totalCount` from the rows**, never `meta.found` (a per-page count on `/v3/locations`): `(page − 1) × limit` plus the stations returned, exact on a short page and a floor flagged `totalCountIsLowerBound` with `truncated` on a full one. ([#27](https://github.com/cyanheads/openaq-mcp-server/issues/27))
- **`openaq_find_locations` fails an empty page past the first with `page_exhausted`** (`NotFound`, data `{page, limit}`) instead of `no_locations_found`'s no-coverage recovery.
- **`openaq_find_locations` `bbox` rejects inverted corners** (`minLon > maxLon` or `minLat > maxLat`) at the schema instead of reaching OpenAQ's HTTP 500; equal corners stay valid.
- **`openaq_find_locations` `iso` is trimmed and uppercased**, since OpenAQ matches it case-sensitively, and accepts the `-99` placeholder `openaq_list_countries` returns for Dhekelia; the `code` output descriptions on both tools name both forms. ([#39](https://github.com/cyanheads/openaq-mcp-server/issues/39))
