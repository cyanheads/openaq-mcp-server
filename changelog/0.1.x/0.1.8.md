# 0.1.8 — 2026-08-24

The framework jump spans the SDK v2 migration, so the wire surface every client
sees changes even though no tool signature did.

## Added

- **`cacheHint` on both resources** — `openaq://location/{locationId}` advertises a 5-minute public TTL (station metadata is near-static, but `datetimeLast` advances), `openaq://parameters` an hour. Honored on protocol revision 2026-07-28; 2025-era `resources/read` responses are unchanged.
- **`.github/CONTRIBUTING.md` and `.github/CODE_OF_CONDUCT.md`** — how to route a bug between this repo and `@cyanheads/mcp-ts-core`, and the conduct terms for the issue tracker.

## Changed

- **`@cyanheads/mcp-ts-core` `^0.11.0` → `^0.12.3`** — `@modelcontextprotocol/sdk` is replaced by `@modelcontextprotocol/server`. The bullets below are the client-visible consequences.
- **Every HTTP endpoint also serves protocol revision `2026-07-28`.** 2025-era clients keep negotiating their own revision on `initialize`; `resources: { subscribe: true }` is now advertised and backed.
- **Tool arguments are strict.** A root-level key no tool declares is rejected by name instead of stripped, and each advertised `inputSchema` carries `additionalProperties: false`. A client that padded calls with extra keys must stop.
- **Advertised schemas emit JSON Schema 2020-12**, not draft-07, and every `outputSchema` declares the `error` envelope — a client validating `structuredContent` without checking `isError` stops rejecting error results with `-32602`.
- **`ctx.log` output reaches the client** as `notifications/message`, gated by `logging/setLevel`. Every line these tools log is client-visible.
- **Argument-validation failures read as flat `path: message` sentences**, and an unknown or disabled tool name rejects with `-32602` rather than resolving an `isError` result.
- **`transport.sessionMode` reports the mode the server runs in.** The landing page and `/.well-known/mcp.json` read `stateless` for the container instead of `auto`.
- **Bun pins move to `1.4.0`** — both `Dockerfile` stages and `packageManager`. `engines.bun` stays `>=1.3.0`.
- **The production image installs without optional peers** — `--omit=peer` on the base install and on the OpenTelemetry add.
- **Retry log lines carry the request's correlation ids** — the OpenAQ service passes `context: ctx` into `withRetry`.
- **`.env.example` documents the new framework knobs** — `MCP_HTTP_RESUMABILITY` / `_MAX_EVENTS` / `_TTL_MS` (SSE replay on a dropped stateful stream) and `MCP_LOG_RATE_LIMIT_THRESHOLD` / `_WINDOW_MS`.
- **Security reports go to `security@caseyjhand.com`.**
- **`tsconfig.json` typechecks `tests/`**, with `tsconfig.build.json` as the emit-only config (`rootDir: src`). The suite's `createMockContext` calls now pass each definition's `errors` contract.
- **Framework scripts, skills, and the changelog template resynced to 0.12.3** — `scripts/lint-mcp.ts`, `scripts/lint-packaging.ts`, `scripts/tree.ts`, `changelog/template.md`, and 25 skills under `skills/`.

## Fixed

- **A cancelled `openaq_get_measurements` aborts instead of degrading.** An abort landing between pages, inside a page fetch, or during canvas staging propagates, rather than being recast as an OpenAQ outage with a partial series or as a DataCanvas failure.
- **`bun run tree` honors directory-only ignore patterns.** Paths were tested without a trailing slash, so `docs/tree.md` listed directories `.gitignore` excludes.
