# 0.1.4 — 2026-07-26

## Added

- **`openaq_list_countries` `parametersId`** — new optional input narrows to countries that measure a given parameter id, answering "which countries have NO2 monitoring?" in one call. Composes with `query`; skips a country whose upstream `parameters` is null rather than throwing. The empty-result notice now names whichever filter(s) missed and points at `openaq_list_parameters` when an id is involved. ([#18](https://github.com/cyanheads/openaq-mcp-server/issues/18))
- **`openaq_find_locations` `page`** — new optional input (1-based, default 1) reaches stations past the 100-station `limit` cap. Truncation guidance now says `request page N+1` instead of `raise limit` once `limit` is already at 100. ([#14](https://github.com/cyanheads/openaq-mcp-server/issues/14))

## Changed

- **`coordinatesSchema`/`bboxSchema` whitespace tolerance** — both strip whitespace via `z.preprocess` before the pattern check, so `"47.6062, -122.3321"` parses identically to its space-free form. Malformed values get a plain-language format message instead of a raw regex dump; `abort: true` on the pattern check stops a non-numeric value from also collecting a bogus out-of-range issue. Advertised `type`/`pattern` in the JSON Schema are unchanged — this is server-side normalization, not a widened contract. ([#17](https://github.com/cyanheads/openaq-mcp-server/issues/17))
- **`openaq_list_countries`/`openaq_list_parameters` empty-result formatting** — `format()` now returns no content block for an empty result, so the framework's unconditional enrichment trailer (`**0 total**` + notice) stands alone instead of duplicating the miss across two blocks. ([#9](https://github.com/cyanheads/openaq-mcp-server/issues/9))
- **`.mcpb` bundling** — `clean-mcpb.ts` also strips platform-specific native bindings (e.g. DuckDB) so the bundle isn't locked to the OS it was packed on. `manifest.json`'s `CANVAS_PROVIDER_TYPE` description and the README now say to leave it `none` in the bundle and use the npm or Docker install for DataCanvas work.
- **Bun supply-chain hardening** — `bunfig.toml` blocks installing package versions published less than 3 days ago (`minimumReleaseAge`, excluding same-day `@cyanheads/mcp-ts-core` adoption) and wires the Socket scanner (`@socketsecurity/bun-security-scanner`) into installs.
- **Dockerfile** — pinned `oven/bun:1.3.14` (was floating `1.3`), added BuildKit cache mounts for Bun's install cache, and `--ignore-scripts` on the build-stage install.
- Repo hygiene — LICENSE copyright year 2025 → 2026; `.gitignore`'s `data/` pattern anchored to the repo root (`/data/`).
- Skill sync — `skills/` and `.claude/skills/` mirror refreshed for the `mcp-ts-core` 0.11.0 adoption below (new `api-mirror` and `techniques` skills; updated `git-wrapup`, `field-test`, `design-mcp-server`, `tool-defs-analysis`, and others).
