# 0.4.1 — 2026-09-26

## Fixed

- **Multi-architecture Docker builds** run production dependency installs and Socket scanning on the native build platform, selecting DuckDB bindings for the target CPU. This avoids QEMU scanner crashes while preserving the release-age guard and framework OpenTelemetry peer ranges. ([#47](https://github.com/cyanheads/openaq-mcp-server/issues/47))
- **Runtime image assembly** copies prepared dependencies, compiled output, and the writable log directory without running build commands under emulation; the server continues to run as the non-root `bun` user.
